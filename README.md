# IRON CORE v10.0 // WebGL 3D & Gym Focus OS (Vite + TypeScript + Three.js + IndexedDB)

## Новинки версии 10.0
- **Интерактивный 3D-разбор нагрузки на WebGL (`Three.js`):** настоящая 3D-штанга с дисками IPF, замками, вращением пальцем, переключением ракурсов (`3D` / `Торец` / `Фронт`), пошаговой сборкой по одному блину и звуком железа.
- **Режим зала (`Gym Focus Mode`):** полноэкранный режим с крупными кнопками под мокрые руки, выбором сложности подхода (`Легко` / `По плану` / `На грани`), живым расчётом `e1RM` и авто-подсказками.
- **Умная кухня и список покупок:** отправка ингредиентов любого рецепта в интерактивный чек-лист покупок в один тап.

## Запуск и сборка
```bash
npm install
npm test
npm run dev
npm run build
```
